下载的文件存在哪

所有内容统一放在总下载目录下（默认 ~/Downloads/DownloadKit），按类型分进子目录：

  • music — 音乐（网易云、QQ音乐、咪咕等）
  • videos — 视频（抖音、B站、YouTube、小红书）
  • images — 图片
  • animated — 实况照片

设置页「下载」组里有只读路径预览，直接列出每个分类实际会落到哪个目录。只有确实要把某一类文件放到别处时，才展开「高级」折叠单独指定 —— 留空即跟随总目录。

v0.4.1 起会把老版本散落在系统下载目录里的 music / videos / animated 文件自动搬进总目录；搬不动的留在原地，原目录非空不会删。

Cookie 怎么配

哪些平台需要：

  • 抖音：需要（否则视频解析失败）—— 不过现在更推荐下面的扫码登录
  • B站：建议配（1080P 高清需要登录）
  • YouTube / 小红书 / 网易云 / QQ音乐 / 咪咕：公开内容不需要

文件格式（任选一种）：

  • 纯文本：name1=value1; name2=value2
  • JSON：{"name1": "value1", "name2": "value2"}
  • Netscape：# Netscape HTTP Cookie File 开头的 tab 分隔格式（yt-dlp 风格）

怎么获取：

  1. 在浏览器（Edge / Chrome）里登录目标网站
  2. 按 F12 → Application → Cookies → 复制需要的键值对
  3. 粘到设置页的文本框，或存成文件后选文件

设置页的「立即读取」能一键从 Edge / Chrome 读取已登录的 Cookie；「登录并获取」会开浏览器窗口帮你完成登录。

抖音扫码登录

创作者订阅功能需要登录抖音。点设置页的「扫码登录抖音」会弹出一个浏览器窗口，用抖音 App 扫码即可，登录一次长期有效，之后不用再管 Cookie。

登录窗口和下载不能同时进行，有下载任务时会暂时无法登录 —— 先把队列清空再扫码。

登录状态随时可以用「刷新状态」复查，「退出登录」也在这里。

代理设置

位置：设置 →「网络」→「代理」

  • 三态开关：关闭 一律直连；跟随系统 用操作系统的代理设置（改完系统代理点「测试连接」确认）；手动 按下方地址走
  • 全局代理：手动模式下对所有平台生效，格式 http://127.0.0.1:7890（Clash / v2rayN 默认端口 7890，以你的代理软件为准）
  • 按平台覆盖：YouTube / 抖音 / B站 / 小红书 各自留空即跟随全局
  • 测试连接：按当前模式测一次连通性和延迟，不通会给出中文原因（超时 / 端口不通）

改完记得保存。访问不了的平台（比如 YouTube）没配代理时，表现就是一直连不上。

常见问题

下载的文件找不到了？
设置 →「下载」组第一行就是总目录，旁边「打开」可以直接打开；下面的只读预览列出每个分类的实际路径。
抖音视频解析失败？
多半是没登录，按上面「抖音扫码登录」扫一次。如果链接本身失效了，重新复制一条分享链接再试。
提示「短链解析失败(1/3) … 后重试」？
程序会自动隔一段时间重试。抖音的分享短链有频率限制，短时间内连续解析容易被挡，稍等几分钟再贴新链接。
歌单解析失败？
原始提示一般就三种原因：歌单不存在、需要登录、或网络问题 —— 先核对链接是否完整，再看网络 / 代理。
文件重名怎么处理？
设置 →「下载」→「文件重名策略」三选一：跳过（默认）/ 自动重命名 / 覆盖。改动需重启生效。
关掉窗口程序还在跑吗？
开「关闭窗口时最小化到托盘」就常驻后台、订阅检查不中断；要开机自启再开「开机自动启动」。这两项都是下次启动生效。
B站想下 1080P？
1080P 需要登录态，给 B站 配上 Cookie 即可，见上面「Cookie 怎么配」。

报错对照

看到的提示多半是怎么办
未捕获到视频流，作品可能不存在或需要登录 抖音未登录，或作品已删除 / 私密 先扫码登录；仍失败就换一条链接
Cookie 文件不存在: 路径 路径填错，或文件被删了 重新选文件，或用「立即读取」
歌单解析失败，可能原因：歌单不存在、需要登录、或网络问题 三种原因之一 核对链接 → 登录 → 检查网络 / 代理
短链解析失败(n/N) … 后重试 抖音短链限流，或网络抖动 等它自己重试；连续失败就隔几分钟再试
返回的不是视频数据（错误页） 视频流签名过期，或被代理拦截 在队列里点重试；再检查代理设置
加载设置失败 / 设置保存失败 后端没起来，或端口被占用 重启程序后重试

拿不准就把设置 →「应用」→「日志级别」调成 DEBUG（需重启），重现一次问题，报错会带出更多信息。
