Cookie 设置 （旧方案，抖音请优先用上面的扫码登录）

🔑 哪些平台需要 Cookie？
✅ 抖音：必须（否则视频解析失败）   ✅ B站：建议（1080P 高清需登录）
❌ YouTube / 小红书 / 网易云：公开内容不需要
📄 Cookie 文件格式（任选一种）：
  • 纯文本：name1=value1; name2=value2
  • JSON：{"name1": "value1", "name2": "value2"}
  • Netscape：# Netscape HTTP Cookie File 开头的 tab 分隔格式（yt-dlp 风格）
🛠 怎么获取 Cookie？
  1. 在浏览器（Edge/Chrome）中登录目标网站
  2. 按 F12 → Application → Cookies → 复制需要的键值对
  3. 粘贴到下方文本框，或保存为文件后再选文件
💡 下方的"从浏览器读取"按钮可以一键从 Edge / Chrome 中读取已登录的 Cookie
